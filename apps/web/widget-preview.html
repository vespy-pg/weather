Choose a launcher grid size. The preview uses 64 x 55 CSS pixels per cell as a stable visual reference.

Current content: 24 hours grouped into 3-hour periods, day and night, sunlight, cloud cover, precipitation, the temperature curve, and wind strength.

Below the temperature header, the vertical layout reserves 20% for sky and precipitation, 70% for the temperature chart, and 10% for wind. Sky height stops growing at four rows, leaving additional space for the chart.

The home-screen widget contains no legend. Tapping it opens the complete forecast and explanation.

The 2-8 column and 1-8 row ranges belong only to this prototype. Android launchers determine the real grid and available size.
